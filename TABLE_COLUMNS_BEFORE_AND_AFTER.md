## What's Displayed in COE/RC Column

### Scenarios

**Scenario 1: Batch has coe.name (object)**
```javascript
batch.coe = {
  name: "Deep Learning in Eye Disease Prognosis",
  coeId: ObjectId(...)
}
Display: "Deep Learning in Eye Disease Prognosis" ?
```

**Scenario 2: Batch has rc.name (object)**
```javascript
batch.rc = {
  name: "Cloud Computing",
  rcId: ObjectId(...)
}
Display: "Cloud Computing" ?
```

**Scenario 3: Batch has coe (string)**
```javascript
batch.coe = "Deep Learning in Eye Disease Prognosis"
Display: "Deep Learning in Eye Disease Prognosis" ?
```

**Scenario 4: Neither COE nor RC**
```javascript
batch.coe = ""
batch.rc = ""

```
